# Hasil pengujian integrasi A2

Pengujian dilakukan pada 18 November 2026 WIB dengan PHP 8.3.26, MySQL Laragon 8.4.3 pada port 3307, dan Chrome headless. PHPUnit memakai SQLite in-memory. Tes browser dan HTTP dari login sampai unduh rapor lulus pada schema `nava_a2_e2e_20261118_run5` yang dimigrasikan dari kosong, dengan penyimpanan PDF privat khusus pengujian.

Percobaan awal mendeteksi tiga masalah integrasi. Git mengabaikan seluruh direktori Blade di backend. Objek Alpine kehilangan getter saat digabung menggunakan object spread. Pengisian jadwal bisa beradu dengan pemuatan ulang data setelah mengganti periode. Aturan ignore, inisialisasi Alpine, dan kondisi form diperbaiki. Selektor browser juga disesuaikan agar menyasar kontrol yang terlihat. Hasil di atas berasal dari pemeriksaan ulang setelah perbaikan terkait.
